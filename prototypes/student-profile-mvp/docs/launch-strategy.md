# WeThru Campus 파일럿 출시 전략

## 1. 이번 대화에서 확인된 가격 신호
- 학생 개인이 가볍게 사는 가격: 약 5만 원
- 취업 준비를 적극적으로 하는 학생: 10만~20만 원 수용 가능성
- 자소서·면접 컨설팅에 추가되는 결과물: 약 20만 원이 설득력 있음

따라서 하나의 가격으로 시작하지 않고 아래 세 층으로 분리한다.

1. Campus Start 49,000원
2. Job Ready 99,000원
3. Career Bundle 199,000원~

## 2. 핵심 가설
- “온라인 명함”보다 “취업용 온라인 프로필”이 학생의 문제로 더 잘 인식된다.
- 에브리타임 직판은 저가 파일럿과 후기 확보에 유효하다.
- 장기 매출은 취업 컨설턴트·학원과의 제휴형이 더 안정적이다.
- 20만 원 제휴형은 자소서·면접에서 이미 정리된 메시지를 웹 결과물로 확장할 때 가장 설득력이 높다.

## 3. 1차 파일럿
- 모집: 10명
- 학교: 3곳
- 게시글: 학교별 2회, 총 6회
- 상품: Start 49,000원 / Job Ready 99,000원
- 무료 제작 금지. 단, 첫 2명은 후기 제공 조건으로 일부 할인 가능
- 직무: 기획·마케팅, 디자인·콘텐츠, 개발·데이터 우선

## 4. 통과 지표
- 랜딩 방문 → 사전 신청: 8% 이상
- 사전 신청 → 결제: 20% 이상
- 한 명당 평균 제작시간: Start 3시간 이내 / Job Ready 5시간 이내
- 평균 수정 요청: 2회 이하
- 완성자 추천 의향: 70% 이상
- 후기·전후 화면 공개 동의: 30% 이상

## 5. 제휴 파일럿
- 대상: 자소서 첨삭, 면접 컨설팅, 취업 학원, 대학 취업지원 프로그램
- 첫 제휴: 업체당 학생 1~3명
- 권장 고객 판매가: 199,000원
- 공급가는 파트너가 자료를 얼마나 정리해서 전달하는지와 월 물량을 기준으로 협의
- 계약 전 확정 항목: 정산일, 환불, 수정 범위, 개인정보 전달, 공개 승인, 하자 대응

## 6. 페이지별 역할
- index.html: 학생 유입과 문제 인식
- samples.html: 결과물 수준 확인
- pricing.html: 가격 부담 해소와 플랜 선택
- apply.html: 결제 전 적합성 확인
- guide.html: 자료 준비 부담 감소
- partner.html: 컨설턴트·학원 B2B 영업
- sample-*.html: 직무별 실제 결과물 체험
- privacy.html: 개인정보 정책 초안

## 7. 출시 전 필수 작업
- 실제 신청 저장소 연결
- 카카오톡 또는 이메일 상담 채널 연결
- 사업자·환불·개인정보 정책 확정
- 실제 도메인 연결: 예) campus.wethru.com
- 첫 고객 3명의 전후 사례 제작
